СТАРТ TRIZ — встановлення
1. Завантажте вміст архіву до папки /triz/ репозиторію -eidos.
2. index.html — оновлена головна сторінка розділу; решта — у /triz/start/.
3. Для кожної з 40 задач заплановане ОКРЕМЕ зображення images/task-01.webp ... task-40.webp.
4. Наразі сторінки показують спільну нейтральну заглушку placeholder.svg, а не готові індивідуальні зображення.
5. Після створення зображень замініть у відповідному task-NN.html src="images/placeholder.svg" на src="images/task-NN.webp".
6. Сторінка каталогу також має мініатюри: замініть src аналогічно для кожної задачі.
7. Власні стилі сторінок додаються локально, тому portal.css не змінюється.
