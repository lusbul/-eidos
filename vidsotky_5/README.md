# Відсотки навколо нас — 5 клас

Оновлення оригінального уроку. Збережено 10 перевірок; додано дві, коротку теорію, рефлексію, облік спроб і звіт.

Розмістіть файли у папці `vidsotky_5/` репозиторію GitHub Pages. Відкрийте `index.html`. Не потрібні сервер, реєстрація чи бібліотеки.

PDF створюється через друк браузера → «Зберегти як PDF». Дані залишаються в поточній вкладці; після перезавантаження не зберігаються.
