Оновлення «Мапа уроку» для уроків 24–47.
Розпакуйте в корінь репозиторію -eidos зі збереженням папок.
У кожному уроці додано кнопку «Мапа уроку» біля PDF.
Уроки 25 та 26: мапа відкриває наданий користувачем великий плакат (локальний WebP).
Уроки 24, 27–47: мапа поки що відкриває друкований огляд етапів, сформований із заголовків уроку. Ілюстровані плакати для них ще не створені.
Нове вікно: можна збільшити зображення та зберегти PDF через кнопку друку.
Жодних зовнішніх ресурсів. Оригінальні JS/CSS уроків не змінено.
